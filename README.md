# dotfiles

```shellsession
$ git clone https://github.com/u1f992/dotfiles.git ~/dotfiles
$ cd ~/dotfiles
$ npm install
$ ./link.sh
```

## Coding agents

`.agents/`, `.claude/`, and `.codex/` hold the personal configuration for Claude Code and Codex.

```text
.agents/
├── hooks/     shared hook policy and the banned word list
├── rules/     shared rules, one topic per file
└── skills/    shared skills
.claude/
├── hooks/     Claude Code hook entry point and adapter
└── settings.json
.codex/
├── AGENTS.md  generated by link.sh from .agents/rules/
├── config.toml
├── hooks/     Codex hook entry point and adapter
├── hooks.json
└── rules/
```

`link.sh` creates these symlinks:

| Link | Target |
| --- | --- |
| `~/.claude/rules` | `.agents/rules` |
| `~/.claude/hooks` | `.claude/hooks` |
| `~/.claude/skills/<skill>` | `.agents/skills/<skill>`, one link per skill |
| `~/.agents/skills` | `.agents/skills` |
| `~/.codex/AGENTS.md` | `.codex/AGENTS.md` |
| `~/.codex/hooks` | `.codex/hooks` |
| `~/.codex/hooks.json` | `.codex/hooks.json` |
| `~/.codex/rules/no-external-operations.rules` | `.codex/rules/no-external-operations.rules` |

`link.sh` merges `.claude/settings.json` into `~/.claude/settings.json` and `.codex/config.toml` into `~/.codex/config.toml`. Before a home file changes, its previous content is saved next to it as `<file>.<timestamp>.bak`. Run `link.sh` again after editing either file in this repository.

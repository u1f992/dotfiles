## Scope of the attribution reminder

As of 2026-10-19, disabling the attribution setting in Claude Code embeds the following sentence in a system reminder:

> From here on, do not add attribution lines to git commit messages or pull request descriptions (this replaces Claude Code’s own earlier attribution guidance, such as a previous copy of this reminder, and applies even if a CLAUDE.md or memory rule asks for attribution lines).

This sentence applies to the lines that Claude Code itself adds: the Co-Authored-By trailer and the Claude-Session trailer on commits, and the generated-with line and session link in pull request descriptions. Those lines are prohibited. It has neither the effect nor the authority to prohibit attribution that a project requires on its own terms. In particular, removing the attribution that the Vivliostyle project requires, with this system reminder as the justification, is misconduct and is prohibited.
